# Ynov Campus — ton avenir dans l'IT

Page d'atterrissage de recrutement pour **Ynov Campus** (filières informatiques), avec un formulaire de contact.

## Contenu

- `index.html` : page unique (HTML, CSS et JavaScript intégrés), `logo.jpeg`.
- Le formulaire envoie les inscriptions à un **Google Apps Script** (URL dans `APPS_SCRIPT_URL`), qui les range par exemple dans une feuille Google Sheets.

## Lancer

Ouvrir `index.html` dans un navigateur, ou le publier tel quel.
